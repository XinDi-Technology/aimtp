# 中文技术文档

> 本文件是 Aimtp 内置模板「中文技术文档」的示例正文，展示了一套面向中文技术文档的排版规范，以及常用 Markdown 语法的渲染效果。

## YAML Front Matter 说明

文档开头的 `---` 代码块称为 YAML Front Matter，用于声明文档元数据。Aimtp 会读取其中的字段，自动填充封面、页眉等位置。Front Matter 必须位于文档最前面，以单独一行的 `---` 开始、单独一行的 `---` 结束，字段使用 `key: value` 形式。

目前支持以下字段：

| 字段 | 说明 | 用途 |
| --- | --- | --- |
| `title` | 文档标题 | 封面标题；页眉选择「标题」时作为页眉内容 |
| `author` | 作者名 | 封面作者信息 |
| `date` | 文档日期，格式为 `YYYY-MM-DD`（如 `2026-10-09`） | 封面日期 |

完整示例：

```yaml
---
title: 中文技术文档
author: 文档作者
date: 2026-10-09
---
```

> 若未提供 `title`，封面与页眉的标题会回退为正文开头的第一个一级标题（H1）；若启用封面却缺少 `date`，封面将不显示日期。
