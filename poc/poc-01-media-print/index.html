Page 1 - First Page

This is the first page of the POC-01 test document. The purpose is to verify that @media print CSS rules are correctly applied by Electron's webContents.printToPDF().

In screen mode, this page has: white background, box-shadow, relative position. In print mode, it should have: static position, break-after:page, no shadow.

Page 2 - Second Page

This is the second page. In the exported PDF, this should appear on a separate page because of break-after: page on the first page.

Key verification points:

Page 3 - Last Page

This is the last page. The last .page should NOT have break-after:page (break-after:auto), so no blank page after it.
